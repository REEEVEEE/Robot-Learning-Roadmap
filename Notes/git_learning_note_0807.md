# 一、Git是什么

Git不是简单的代码上传工具。

它是一个：

> 记录项目变化历史的版本管理系统。

核心作用：

-   保存项目不同阶段状态
-   查看过去修改
-   回退错误版本
-   支持多人协作开发

------------------------------------------------------------------------

# 二、Git核心概念

## 1. Repository（仓库）

Git管理的项目文件夹。

例如：

Robot-Learning-Roadmap

里面包含：

-   Cpp
-   STM32
-   ROS2
-   Control
-   Notes
-   Projects

------------------------------------------------------------------------

## 2. Working Directory（工作区）

当前电脑中正在修改的文件。

例如：

修改 PID.cpp：

``` cpp
Kp = 1.5;
```

此时只是文件变化，Git还没有保存。

------------------------------------------------------------------------

## 3. Stage（暂存区）

通过：

``` bash
git add
```

告诉Git：

"这个修改我要准备保存。"

------------------------------------------------------------------------

## 4. Commit（提交）

通过：

``` bash
git commit -m "说明"
```

保存一个版本。

理解：

commit = 给项目当前状态拍一张照片。

例如：

``` bash
git commit -m "Tune motor PID parameters"
```

表示：

完成了一次PID参数优化版本。

------------------------------------------------------------------------

## 5. Push

通过：

``` bash
git push
```

把本地commit上传到GitHub。

------------------------------------------------------------------------

# 三、今天掌握的基本流程

标准开发流程：

    修改代码

    ↓

    git status

    ↓

    git add

    ↓

    git commit -m "说明"

    ↓

    git push

含义：

1.  修改项目
2.  查看变化
3.  选择需要保存的内容
4.  保存版本
5.  上传远程仓库

## 解决第一次Git冲突

遇到：

    rejected (fetch first)

原因：

本地和GitHub存在不同历史。

解决：

``` bash
git pull origin main --allow-unrelated-histories
```

然后：

解决README冲突。

理解：

merge冲突产生原因：

两个地方同时修改同一个内容，Git无法判断保留哪个。

# 五、已经掌握的命令

## 查看状态

``` bash
git status
```

作用：

查看当前文件修改情况。

------------------------------------------------------------------------

## 添加文件

``` bash
git add 文件名
```

作用：

把修改加入下一次commit。

------------------------------------------------------------------------

## 提交版本

``` bash
git commit -m "message"
```

作用：

保存一个版本。

------------------------------------------------------------------------

## 上传

``` bash
git push
```

作用：

上传到远程仓库。

------------------------------------------------------------------------

## 查看历史

``` bash
git log --oneline
```

作用：

查看提交记录。

------------------------------------------------------------------------

## 放弃未提交修改

``` bash
git restore 文件名
```

作用：

恢复到上一次commit状态。
